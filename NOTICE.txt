The build embedded in index.html is the unmodified single-threaded
@mujoco/mujoco 3.11.0 WebAssembly package, gzipped and base64-encoded so the
page needs no network at run time. It is not otherwise altered.

Everything else in this folder is Marcel Padilla's own work.

The explosion sprite sheet, envs/assets/explosion.webp in the project tree, is
baked from a Creative Commons green-screen clip supplied by Marcel Padilla, who
states he holds full rights to use it. The clip itself is not redistributed here;
only the derived 16-cell sheet is, inside index.html.
